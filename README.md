# NewsAnalizer

Локальний аналізатор новинних відео з YouTube. На вхід — посилання, на виході —
стисле структуроване розвідувальне зведення (`.md`), зібране локальною LLM. Без
хмарних сервісів: текст відео і його аналіз не залишають машину.

Заточено під українські воєнні новинні ефіри (огляди фронту, удари, економіка РФ,
дипломатія), але працює і з російськомовними джерелами — зведення завжди
українською.

---

## Що вміє

- **Бере текст відео** трьома способами (каскад): субтитри YouTube
  (`youtube-transcript-api`) → резервні субтитри `yt-dlp` → **розпізнавання
  мовлення WhisperX** для відео без субтитрів (записи прямих ефірів).
- **Розрізняє спікерів** (діаризація pyannote) на ASR-шляху — мітки `[Спікер N]`
  для діалогів «ведучий + гість».
- **Розуміє розділи** відео (chapters) — подає їх у LLM як підказку про структуру.
- **Гібридний аналіз за типом контенту** (LLM-класифікатор обирає формат):
  - **ROUNDUP** (швидке новинне зведення, NEXTA-стиль) → рубрики `[ФРОНТ]`,
    `[УДАРИ]` (напрямок `хто > по кому`), `[ЛОГІСТИКА]`, `[ЕКОНОМІКА РФ]`,
    `[ВНУТРІШНЯ РФ]`, `[УКРАЇНА]`, `[ДИПЛОМАТІЯ]`, `[ПИТАННЯ-ВІДПОВІДІ]` — без
    спікер-атрибуції (канал ретранслює новини).
  - **ANALYSIS** (розбір одного аналітика) → 2 проходи: спершу плоский список
    фактів/думок із типом `(подія)`/`(дані)`/`(думка)` та атрибуцією, потім
    сортування за вільними темами + «Різне».
- **Зберігає атрибуцію й джерела**: хто озвучив + на що спирається («за даними
  розвідки»), маркує неперевірене `[!]`, цитати — `[цит. …]`.
- **Батч-режим** за замовчуванням: список посилань через кому, помилка одного
  відео не валить решту.

## Як працює

```
URL
 ├─ метадані (yt-dlp): канал, дата, назва, тривалість, розділи
 ├─ текст:
 │    субтитри (transcript-api → yt-dlp)         ── режим "субтитри" (0)
 │    АБО розпізнавання аудіо (WhisperX + діаризація) ── режим "аудіо" (1)
 ├─ аналіз: Ollama / gemma4 + prompt.txt
 └─ звіт: output/Ефір <канал> - <тема> - <дата> - <час доби>.md
```

LLM сама формує ім'я файлу (канал, тема, дата, час доби) — код лише чистить
заборонені символи. «Красивий» заголовок лишається як H1 усередині файлу.

## Встановлення

**Вимоги:** Python 3.12, [Ollama](https://ollama.com) з моделлю
`gemma4:26b-a4b-it-qat`, `ffmpeg` (для ASR).

```powershell
# 1. Віртуальне середовище
py -3.12 -m venv .venv

# 2. Базові залежності (субтитровий шлях — без важкого ML-стеку)
.venv\Scripts\python.exe -m pip install -r requirements.txt

# 3. Модель Ollama
ollama pull gemma4:26b-a4b-it-qat

# 4. ffmpeg
winget install Gyan.FFmpeg
```

### Опційно: розпізнавання мовлення (WhisperX)

Потрібне лише для відео **без субтитрів**. Важкий стек (torch + CUDA), тому
окремо:

```powershell
# torch під свою відеокарту (приклад cu128 / RTX 40xx-50xx)
.venv\Scripts\python.exe -m pip install torch==2.8.0 torchaudio==2.8.0 `
    --index-url https://download.pytorch.org/whl/cu128

.venv\Scripts\python.exe -m pip install -r requirements-asr.txt
```

**Діаризація** (розрізнення спікерів) додатково потребує токена HuggingFace і
прийнятої ліцензії [`pyannote/speaker-diarization-community-1`](https://huggingface.co/pyannote/speaker-diarization-community-1).
Отримати токен: https://huggingface.co/settings/tokens

```powershell
# Варіант 1: файл .env у корені проєкту (рекомендовано)
copy .env.example .env
# відкрити .env і вставити токен

# Варіант 2: змінна середовища ОС
[Environment]::SetEnvironmentVariable("HF_TOKEN", "hf_...", "User")
```

`.env` у `.gitignore` — токен ніколи не потрапить у git. Без `HF_TOKEN` ASR
працює, але без міток спікерів.

## Використання

```powershell
# Інтерактивно: спитає посилання й джерело тексту
python run.py

# Одне або кілька відео (через кому/пробіл/новий рядок)
python run.py "https://youtu.be/AAA, https://youtu.be/BBB"

# Примусове розпізнавання аудіо (з діаризацією, якщо є HF_TOKEN)
python run.py --asr "https://youtu.be/AAA"

# Тільки субтитри (дефолт)
python run.py --subs "https://youtu.be/AAA"
```

| Прапорець | Дія |
|---|---|
| `--subs`, `-s` | джерело — субтитри (за замовчуванням) |
| `--asr`, `-a` | джерело — розпізнавання аудіо WhisperX |

Звіти зберігаються в `output/`. Сирі транскрипти кешуються в `cache/`
(`<id>.txt` — субтитри, `<id>.asr.txt` — ASR), щоб не тягнути двічі.

## Налаштування

**Промпти** (редагуються без зміни коду):
- `prompt_classify.txt` — класифікатор ROUNDUP / ANALYSIS;
- `prompt_roundup.txt` — рубричний формат (швидкі зведення);
- `prompt_analysis_extract.txt` — плоский список фактів/думок (розбори);
- `prompt_analysis_sort.txt` — сортування списку за темами.

**`src/config.py`** — константи:

| Константа | Призначення |
|---|---|
| `MODEL` | модель Ollama (`gemma4:26b-a4b-it-qat`) |
| `NUM_CTX` | контекст (65536; зменшіть до 16-32k на GPU з малою VRAM) |
| `ANALYZE_TEMP` | температура аналізу (0.2 — точна екстракція) |
| `WHISPER_MODEL` | модель ASR (`large-v3`) |
| `WHISPER_DEVICE` | `cuda` / `cpu` |

## Обмеження

- **Розрізнення спікерів — лише на ASR-шляху.** Субтитри YouTube не містять міток
  спікерів, тож для відео з субтитрами імен спікерів немає в принципі. Щоб дістати
  їх — ганяйте через `--asr`.
- **Екранний текст не зчитується.** Якщо джерело/цитата показані лише на картинці
  (титр), а в аудіо звучить інакше — у транскрипт потрапляє лише почуте.
- **Діаризація монологу** інколи хибно ділить одного спікера на двох (вступ із
  музикою/зміна інтонації).

## Структура проєкту

```
run.py                 — точка входу: парсинг посилань, батч (2 фази), режим джерела
prompt_classify.txt        — класифікатор формату ROUNDUP / ANALYSIS
prompt_roundup.txt         — рубричний формат
prompt_analysis_extract.txt — плоский список (розбори), прохід 1
prompt_analysis_sort.txt   — сортування за темами, прохід 2
requirements.txt       — базові залежності (субтитровий шлях)
requirements-asr.txt   — ASR-стек (WhisperX), опційно
src/
  config.py            — константи, шляхи, load()
  metadata.py          — yt-dlp: канал, дата, назва, розділи
  transcript.py        — каскад субтитри → ASR, розмітка розділів, кеш
  asr.py               — WhisperX → текст (+ опційна діаризація), окремий процес
  llm.py               — обгортка Ollama (старт/чат/зупинка)
  analyze.py           — класифікація, диспетчеризація, парсинг імені, запис звіту
output/                — звіти .md (gitignored)
cache/                 — кеш транскриптів (gitignored)
```
